# warframe-item-pull
Pull from the warframe community developers for all item information

## Linking to a Personal GitHub Repository

To push this repository to your own GitHub account, add a personal remote and push:

```bash
git remote add personal https://github.com/YOUR_USERNAME/YOUR_NEW_REPO.git
git push personal HEAD
```

Replace `YOUR_USERNAME` with your GitHub username and `YOUR_NEW_REPO` with the name of your new repository.
